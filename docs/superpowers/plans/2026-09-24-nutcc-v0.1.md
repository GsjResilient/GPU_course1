## 统一接口与数据约定

这些接口在各任务中实现，后续任务不得自行另起同义接口。Python 3.9 使用 `Optional`、`Tuple`、`List`，不依赖 3.10 的联合类型语法。

```python
# diagnostics.py
@dataclass(frozen=True)
class SourceLoc:
    file: str
    line: int
    column: int

class CompileError(Exception):
    def __init__(self, code: str, message: str, loc: SourceLoc):
        self.code, self.message, self.loc = code, message, loc
        super().__init__(f"{loc.file}:{loc.line}:{loc.column}: {code}: {message}")

# frontend.py / validate.py：节点保存 Clang 原始类型和位置，不以名字替代声明 ID。
@dataclass
class ParsedUnit:
    source: Path
    source_bytes: bytes
    ast: dict
    clang_version: str
    dependencies: Dict[str, str]  # 文件 SHA-256

@dataclass
class KernelAST:
    unit: ParsedUnit
    name: str
    node: dict
    parameters: List[dict]

def parse_source(source: Path, clang: str = "clang++") -> ParsedUnit: ...
def validate_kernel(unit: ParsedUnit, name: str) -> KernelAST: ...

# ir.py：VReg 的类型为 i32/u32/u8/f32/bool/ptr_u8/ptr_i32/ptr_u32/ptr_f32。
@dataclass(frozen=True)
class VReg:
    id: int
    kind: str

@dataclass
class IRInst:
    op: str
    dst: Optional[VReg]
    args: Tuple[VReg, ...]
    imm: Optional[int]
    guard: Optional[VReg]  # None=所有有效 lane；其余为规范化 0/1 布尔值
    loc: SourceLoc

@dataclass
class Program:
    name: str
    params: List[dict]   # name/kind/offset/size/readonly
    param_size: int
    instructions: List[IRInst]

def lower_kernel(kernel: KernelAST) -> Program: ...

# regalloc.py / backend.py
@dataclass
class Allocation:
    registers: Dict[int, int]
    regs_u32: int

@dataclass
class MachineProgram:
    name: str
    words: List[int]
    listing: List[str]
    params: List[dict]
    param_size: int
    regs_u32: int

def allocate(program: Program, limit: int = 255) -> Allocation: ...
def generate(program: Program) -> MachineProgram: ...

# artifact.py / driver.py：成功返回 manifest 路径；失败抛 CompileError。
def write_artifact(machine: MachineProgram, unit: ParsedUnit, prefix: Path) -> Path: ...
def load_artifact(manifest: Path) -> Tuple[dict, bytes]: ...
def compile_file(source: Path, kernel: str, prefix: Path,
                 clang: str = "clang++") -> Path: ...

# runtime.py / build.py
class RunError(Exception): pass

@dataclass(frozen=True)
class BufferRef:
    name: str
    offset: int = 0

@dataclass
class RunResult:
    buffers: Dict[str, bytes]
    instructions: int
    cycles: int
    completed: bool
    trace: List[Tuple[int, int, int]]  # Func 模式可选：pc, op, exec_mask

def build_tools(out: Path, cxx: str = "clang++") -> Dict[str, Path]: ...
def run_artifact(manifest: Path, backend: str, buffers: Dict[str, bytes],
                 args: List[object], grid: Tuple[int, int, int],
                 block: Tuple[int, int, int], out: Path,
                 timeout_s: float = 20.0, max_steps: int = 10000000,
                 trace: bool = False) -> RunResult: ...
```

上面省略号仅表示接口声明，不是允许实现时留下空函数。每个函数的实现步骤和失败测试在下方所属任务中定义。`args` 每项只允许与 manifest 匹配的 Python int、float 或 BufferRef，不做隐式参数类型推断。

def test_parameter_layout(self):

- [ ] **实现参数和基础表达式。** 参数偏移为 `8 * ordinal`，总区间为 `8 * count`；ptr 槽为 u64，但生成 param 只读取低32位，运行层负责检查高位。每个局部声明用独立 ID 对应可更新 VReg，表达式结果使用新 VReg；初始化和值读取分开记录。保持赋值、复合赋值及访存源代码顺序，不做可能改变 alias 行为的 load/store 重排。

```python
def byte_offset(index: VReg, element_size: int, emit_const, emit_binary) -> VReg:
    if element_size == 1:
        return index
    scale = emit_const(4, index.kind)
    return emit_binary('mul', index, scale, index.kind)
```

数组地址为 ptr 低字加字节偏移；调用此辅助函数时两个整数操作数类型一致。其后 address 使用 ptr 类型，不经源级 int→pointer 转换。限定源级合法数组访问，不能添加“截断后的地址也正确”的承诺。字节 load 生成 u8，再无损提升为 i32。

- [ ] **处理常量和运算语义。** i32/u32 常量按目标位宽保存。浮点常量依据 Clang 类型 AST 数值正确舍入到 binary32；用精确十进制/十六进制有理数到 binary32 的 RN 舍入函数，避免十进制→Python double→float 的双重舍入边界。该函数位于 lower.py，签名 `f32_literal_bits(text: str) -> int`；支持正负零和 subnormal，常量溢出在前端诊断。负号作为一元运算处理；FP32 取负用位型 sign-bit xor，保留负零。不得用 `0.0f - x` 替代所有取负。

测试固定 `0.1f→0x3dcccccd`、`-0.0f→0x80000000`、最近偶数中点、最小正 subnormal；测试运算优先级和作用域遮蔽。拒绝读取未初始化局部变量，错误代码 `E_UNINITIALIZED`。

**Files:** 扩展 lower.py/validate.py；新增 test_control.py。

```cpp

    int x = 0;
    if (x == 0) { x = 1; } else { x = 2; }
    out[threadIdx.x] = x;
}
```

测试 `if (i < n && in[i] > 0)` 的 RHS load、嵌套 false 父条件、`if (false)` 无 store、`if (true)` 无多余谓词、NaN 条件逻辑取反、局部变量仅单分支赋值后读取须拒绝。

Run: `python3 -m unittest compiler.tests.test_control -v`，先确认条件和循环转换失败。

- [ ] **实现条件快照和掩码。** 每个条件转成新的规范化 bool 值，即使原表达式已经是 bool 局部变量也要复制快照；then/else 共用它。构造 `then_mask=parent & condition`、`else_mask=parent & (condition xor 1)`；根 parent 是常量 true。条件内部每个 load/store 及可更新局部变量受 parent 保护。短路 AND 的 RHS mask 是 parent&left；OR 是 parent&!left；不能用 SELP 代替 RHS 的求值控制。

```python
# 每次 if 都保留原 condition 快照，不能重新求值 else 条件。
saved = materialize_bool(condition_ast, parent_mask)
then_mask = bool_and(parent_mask, saved)
else_mask = bool_and(parent_mask, bool_not(saved))
lower_statement(then_ast, then_mask)
lower_statement(else_ast, else_mask)
```

这里的 materialize_bool/bool_and/bool_not/lower_statement 是 lower.py 的 Builder 方法；返回 VReg 或修改其 Program。masked 临时值只有在定义 mask 内可使用；未命中 lane 参与后续逻辑时必须被 parent=0 屏蔽。赋值保留其他 lane 的旧寄存器内容。定义状态在两个分支结束后取交集，若条件是已证明常量则选择实际分支状态。

- [ ] **实现规范循环展开与预算。** 只接受 int 归纳变量从0开始、`k<C`、前缀 `++k`，C∈[0,256]。禁止在 body 修改、取地址或使归纳变量逃逸；每轮建立独立词法作用域，将 k 作为整型常量。嵌套展开检查预算，避免先构造指数级 AST；后端最终机器指令数再检查 4096。零次循环不产生运行指令，body 仍经过前端子集检查。

测试 0/1/3/256 次及2层小循环；257次、动态上限、改变 k、break、提前 return、超预算均报错；资源诊断包含实际数量和上限。

- [ ] **回归并提交。** 重跑前三组测试；提交 `feat(nutcc): predicate conditions and unroll bounded loops`。
